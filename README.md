BoltSizeIndicator

A mod for My Summer/Winter Car that indicates with a color if a bolt is larger or smaller than the tool you're holding.

Dependencies

MSCLoader — Mod loader for My Summer Car.
https://github.com/piotrulos/MSCModLoader

OASIS — Required for the additional BoltSizeIndicatorOASIS.
https://github.com/Horsey4/OASIS
